# S7-F1-C1: Add Icons to Sidebar Navigation

**Sprint:** 7 — Settings Modernization
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Add icons to each sidebar navigation item in SettingsDialog.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Define icon mapping (using Unicode or simple SVG):**
   ```python
   TAB_ICONS = {
       "General": "⚙",
       "Appearance": "🎨",
       "Shortcuts": "⌨",
       "Export": "📤",
       "Reminders": "🔔",
       "Advanced": "🔧",
       "Help": "❓",
   }
   ```

2. **Update sidebar button creation to include icon:**
   ```python
   for tab_name in self.TAB_NAMES:
       icon = TAB_ICONS.get(tab_name, "")
       btn = QPushButton(f"  {icon}  {tab_name}")
       btn.setObjectName("sidebarButton")
       btn.clicked.connect(lambda _, name=tab_name: self._switch_tab(name))
       self._sidebar_layout.addWidget(btn)
   ```

3. **Style sidebar buttons** (add to theme.py):
   ```css
   QPushButton#sidebarButton {
       text-align: left;
       padding: 8px 12px;
       border: none;
       border-radius: 6px;
       font-size: 13px;
   }
   QPushButton#sidebarButton:hover {
       background: rgba(255, 255, 255, 0.05);
   }
   QPushButton#sidebarButton:checked {
       background: rgba(255, 255, 255, 0.1);
       font-weight: bold;
   }
   ```

**ACCEPTANCE CRITERIA:**
- Each sidebar tab has an icon prefix
- Icons are visible in Dark, Light, and OLED themes
- Hover and checked states styled consistently
