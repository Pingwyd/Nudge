# S7-F1-C4: Apply Theme-Aware Styling

**Sprint:** 7 — Settings Modernization
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Ensure all new widgets (sidebar icons, theme cards, toggle switches) respect Dark/Light/OLED themes.

**FILES:** `src/frontend/theme.py`, `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Add theme tokens for new widgets in `get_theme()`:**
   ```python
   "sidebar_hover": "rgba(255, 255, 255, 0.05)" if theme_id != "light" else "rgba(0, 0, 0, 0.05)",
   "sidebar_active": "rgba(255, 255, 255, 0.1)" if theme_id != "light" else "rgba(0, 0, 0, 0.1)",
   "card_border": "#4fc3f7",
   "toggle_on": "#4fc3f7",
   "toggle_off": "#666666",
   ```

2. **Update ToggleSwitchWidget to use theme tokens:**
   ```python
   def paintEvent(self, event):
       theme = get_theme(normalize_theme_id(self._main_window.app_state.get("theme", "dark")))
       on_color = theme["colors"]["toggle_on"]
       off_color = theme["colors"]["toggle_off"]
       # ... use on_color/off_color in painter
   ```

3. **Update ThemeCardWidget to use theme tokens for borders/backgrounds.**

**ACCEPTANCE CRITERIA:**
- All new widgets render correctly in Dark, Light, and OLED themes
- No invisible text or borders in any theme
- Toggle switch colors match theme accent
