# S7-F1-C3: Implement iOS-Style Toggle Switches

**Sprint:** 7 — Settings Modernization
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Create iOS-style toggle switch widget for boolean settings.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create ToggleSwitchWidget:**
   ```python
   class ToggleSwitchWidget(QCheckBox):
       def __init__(self, parent=None):
           super().__init__(parent)
           self.setFixedSize(51, 31)
           self._circle_pos = 4 if not self.isChecked() else 27
       
       def paintEvent(self, event):
           painter = QPainter(self)
           painter.setRenderHint(QPainter.RenderHint.Antialiasing)
           
           # Background
           if self.isChecked():
               painter.setBrush(QBrush(QColor("#4fc3f7")))
           else:
               painter.setBrush(QBrush(QColor("#666666")))
           painter.setPen(Qt.PenStyle.NoPen)
           painter.drawRoundedRect(0, 0, 51, 31, 15, 15)
           
           # Circle
           painter.setBrush(QBrush(QColor("white")))
           painter.drawEllipse(self._circle_pos, 4, 23, 23)
       
       def nextCheckState(self):
           super().nextCheckState()
           self._circle_pos = 4 if not self.isChecked() else 27
           self.update()
   ```

2. **Replace QCheckBox with ToggleSwitchWidget for boolean settings:**
   ```python
   # Example: Run on Startup toggle
   self._startup_toggle = ToggleSwitchWidget()
   self._startup_toggle.setChecked(self.app_state.get("autoStart", False))
   self._startup_toggle.stateChanged.connect(lambda s: self.app_state.__setitem__("autoStart", s == Qt.CheckState.Checked.value))
   ```

3. **Apply to all boolean settings** in General, Appearance, and Advanced tabs.

**ACCEPTANCE CRITERIA:**
- Toggle switches render with iOS-style circular knob
- Smooth visual transition when toggled
- Matches glass theme (accent color for checked state)
- All boolean settings converted to toggle switches
