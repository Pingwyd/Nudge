# S7-F1-C2: Create Theme Grid-Card Selection

**Sprint:** 7 — Settings Modernization
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Replace plain text theme selection with visual grid-cards showing theme preview.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create ThemeCardWidget:**
   ```python
   class ThemeCardWidget(QFrame):
       def __init__(self, theme_id, theme_name, colors, parent=None):
           super().__init__(parent)
           self.theme_id = theme_id
           self.setFixedSize(120, 80)
           self.setCursor(Qt.CursorShape.PointingHandCursor)
           
           layout = QVBoxLayout(self)
           layout.setContentsMargins(8, 8, 8, 8)
           
           # Preview swatch
           preview = QFrame()
           preview.setStyleSheet(f"background: {colors['bg']}; border: 2px solid {colors['border']}; border-radius: 6px;")
           preview.setFixedHeight(40)
           layout.addWidget(preview)
           
           # Theme name
           name = QLabel(theme_name)
           name.setAlignment(Qt.AlignmentFlag.AlignCenter)
           name.setStyleSheet(f"color: {colors['text']}; font-size: 11px;")
           layout.addWidget(name)
           
           self.setStyleSheet(f"border: 2px solid transparent; border-radius: 8px;")
       
       def set_selected(self, selected):
           if selected:
               self.setStyleSheet("border: 2px solid #4fc3f7; border-radius: 8px;")
           else:
               self.setStyleSheet("border: 2px solid transparent; border-radius: 8px;")
   ```

2. **Replace theme combo box with grid layout:**
   ```python
   theme_layout = QHBoxLayout()
   self._theme_cards = {}
   
   for theme_id in ["dark", "light", "oled"]:
       colors = get_theme(theme_id)["colors"]
       card = ThemeCardWidget(theme_id, theme_id.capitalize(), colors)
       card.mousePressEvent = lambda _, tid=theme_id: self._select_theme(tid)
       theme_layout.addWidget(card)
       self._theme_cards[theme_id] = card
   
   # Highlight current theme
   current_theme = self.app_state.get("theme", "dark")
   self._theme_cards[current_theme].set_selected(True)
   ```

3. **Add select method:**
   ```python
   def _select_theme(self, theme_id):
       for tid, card in self._theme_cards.items():
           card.set_selected(tid == theme_id)
       self.app_state["theme"] = theme_id
   ```

**ACCEPTANCE CRITERIA:**
- Theme selection shows 3 visual cards (Dark, Light, OLED)
- Cards show color preview swatch
- Selected card has highlight border
- Clicking card selects theme immediately (live preview)
