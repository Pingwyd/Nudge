# S4-F3-C1 — Add X Button to UndoToast

**PROMPT ID:** S4-F3-C1
**MODEL:** DeepSeek V4 Flash
**TYPE:** Pure-Logic
**DEPENDS ON:** none
**TOUCHES EXISTING CODE:** Yes — UndoToast in main_window.py

---

**OBJECTIVE:** Add a dismiss (X) button to the undo toast that closes it without performing the undo action.

**ROOT CAUSE:** Users must wait for the 5-second timeout to dismiss the toast.

**REQUIREMENTS:**

1. In `UndoToast.__init__()`, add an X button after the "Undo" button:
   ```python
   dismiss_btn = QPushButton("✕")
   dismiss_btn.setObjectName("ghostButton")
   dismiss_btn.setCursor(Qt.CursorShape.PointingHandCursor)
   dismiss_btn.setFixedSize(20, 20)
   dismiss_btn.clicked.connect(self._dismiss)
   layout.addWidget(dismiss_btn)
   ```

2. The X button calls `_dismiss()` directly — same as timeout, no undo performed.

3. Style the X button:
   - Small, subtle (20x20px)
   - Uses `ghostButton` object name for theme consistency
   - Font size smaller than "Undo" button

**FILES TO MODIFY:**
- `src/frontend/main_window.py` — `UndoToast.__init__()`

**ACCEPTANCE CRITERIA:**
- X button appears on the right edge of the toast, after "Undo"
- Clicking X dismisses the toast without undoing
- "Undo" button still works as before
- Auto-dismiss timeout still works
- X button styled consistently with glass theme

**EDGE CASES:**
- Clicking X while timer is running: timer stops, toast dismissed
- Clicking Undo after clicking X: impossible (toast already destroyed)
- Rapid click on X: no crash (deleteLater handles cleanup)
