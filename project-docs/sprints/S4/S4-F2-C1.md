# S4-F2-C1 — Add Search Bar + Live Filter to HistoryDialog

**PROMPT ID:** S4-F2-C1
**MODEL:** DeepSeek V4 Flash
**TYPE:** Pure-Logic
**DEPENDS ON:** S4-F1-C1
**TOUCHES EXISTING CODE:** Yes — HistoryDialog in main_window.py

---

**OBJECTIVE:** Add a live-search bar to the History dialog that filters entries as the user types.

**ROOT CAUSE:** Users with many completed tasks can't quickly find a specific entry.

**REQUIREMENTS:**

1. Add a `QLineEdit` search bar in `HistoryDialog.init_ui()`:
   - Position: below the checkbox (S4-F1-C1), above the scroll area
   - Placeholder text: "Search history..."
   - Style: glass-theme matching (use `_apply_theme()` in HistoryDialog)

2. Connect `search_bar.textChanged` signal to a new `_filter_history()` method:
   ```python
   def _filter_history(self, text):
       query = text.strip().lower()
       for row in self.rows:
           task_text = row.task_ref.get("text", "").lower()
           row.setVisible(not query or query in task_text)
   ```

3. When search bar is empty, all entries are shown.

4. Style the search bar:
   - Use `QLineEdit` base styling from theme.py
   - Add a search icon placeholder or just use placeholder text
   - Match glass theme border/background

**FILES TO MODIFY:**
- `src/frontend/main_window.py` — `HistoryDialog.init_ui()`, new `_filter_history()` method

**ACCEPTANCE CRITERIA:**
- Search bar appears between checkbox and scroll area
- Typing filters history entries in real-time (case-insensitive substring)
- Empty search shows all entries
- Search bar styled to match glass theme
- Search persists while dialog is open (clearing search shows all)

**EDGE CASES:**
- Search with no results: all rows hidden, title still shows full count
- Search with special characters: no regex, simple `in` check
- Very long search text: QLineEdit handles naturally
