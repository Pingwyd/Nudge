# S4-F4-C1 — Group Drag Architecture

**PROMPT ID:** S4-F4-C1
**MODEL:** MiMo V2.5
**TYPE:** Architecture-Reasoning
**DEPENDS ON:** none
**TOCHES EXISTING CODE:** Yes — TaskGroupSection, MainWindow

---

**OBJECTIVE:** Design the architecture for group drag-and-reorder and drag-out-to-text-editor.

**ROOT CAUSE:** Groups can only be reordered by editing groups.json manually.

**CURRENT STATE:**
- `TaskGroupSection` handles task drops (lines 177-208 in task_group_section.py)
- `TaskRowWidget` has QDrag with `application/x-nudge-task-row` MIME type (lines 409-424 in main_window.py)
- `groups_data["groups"]` is a list of group dicts with `id`, `name`, `expanded` keys

**DESIGN REQUIREMENTS:**

1. **MIME types:**
   - Internal: `application/x-nudge-group` — for reordering within the app
   - External: `text/plain` — for dragging to text editors
   - Plain text format: `"Group Name\n- Task 1\n- Task 2\n..."`

2. **Drag source:** `TaskGroupSection.header_btn` mousePressEvent/mouseMoveEvent

3. **Drop targets:**
   - Internal: `MainWindow.tasks_widget` (between group sections)
   - External: Any text editor (Qt handles natively via text/plain)

4. **Reorder logic:**
   - On internal drop, compute target index from drop position
   - Reorder `groups_data["groups"]` list
   - Save to groups.json
   - Re-render task list

5. **Drop indicator:** Horizontal line between groups during drag

**EDGE CASES:**
- Drag in flat mode (groups disabled): no-op
- Drag to same position: no change
- Multiple rapid drags: debounce or queue

**EXPECTED OUTPUT:**
- Data flow design for group drag
- MIME type specification
- Drop target handling
- Reorder logic
