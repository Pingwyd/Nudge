# S4-F4-C2 — Implement Group Drag + Drop Reorder + External Paste

**PROMPT ID:** S4-F4-C2
**MODEL:** DeepSeek V4 Flash
**TYPE:** Pure-Logic
**DEPENDS ON:** S4-F4-C1
**TOUCHES EXISTING CODE:** Yes — TaskGroupSection, MainWindow

---

**OBJECTIVE:** Implement group drag-and-reorder with QDrag and MIME types.

**REQUIREMENTS (from C1 design):**

1. In `TaskGroupSection`, make `header_btn` draggable:
   - Add `mousePressEvent`, `mouseMoveEvent`, `mouseReleaseEvent`
   - On drag start: create `QDrag` with `QMimeData`
   - Set MIME data:
     - `application/x-nudge-group`: group ID bytes
     - `text/plain`: group name + tasks as formatted text
   - Create ghost pixmap from header_btn grab
   - Execute drag with `drag.exec(Qt.DropAction.MoveAction)`

2. In `MainWindow`, handle group drops on `tasks_widget`:
   - `dragEnterEvent`: accept if MIME has `application/x-nudge-group`
   - `dragMoveEvent`: show drop indicator between groups
   - `dropEvent`: compute target index, reorder `groups_data["groups"]`, save, re-render

3. Build external text format:
   ```python
   group_name = self.group.get("name", "Group")
   task_texts = [row.task_ref.get("text", "") for row in self.task_rows]
   plain_text = f"{group_name}\n" + "\n".join(f"- {t}" for t in task_texts)
   mime.setText(plain_text)
   ```

4. Drop indicator:
   - Reuse existing `_drop_indicator` from TaskGroupSection
   - Position between groups based on drop Y coordinate
   - Show during drag, hide on drop/leave

**FILES TO MODIFY:**
- `src/frontend/task_group_section.py` — add drag events to header_btn
- `src/frontend/main_window.py` — handle group drops in tasks_widget

**ACCEPTANCE CRITERIA:**
- Dragging group header shows ghost image
- Internal drops reorder groups correctly
- External drops paste group name + tasks to text editor
- Drop indicator visible during drag
- Groups persist to groups.json after reorder
- No conflict with existing task drag (distinct MIME types)

**EDGE CASES:**
- Drop on same position: no-op, no re-render
- Drop in flat mode: reject drag
- Rapid drags: each drag starts fresh (previous cancelled)
