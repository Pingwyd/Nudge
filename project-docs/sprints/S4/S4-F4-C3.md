# S4-F4-C3 — Verify Group Drag in All Scenarios

**PROMPT ID:** S4-F4-C3
**MODEL:** MiMo V2.5
**TYPE:** Integration-Test
**DEPENDS ON:** S4-F4-C2
**TOUCHES EXISTING CODE:** Yes — TaskGroupSection, MainWindow

---

**OBJECTIVE:** Verify group drag works correctly in all scenarios.

**SCENARIOS:**

1. **Internal reorder:**
   - Drag Group A below Group B → Group A moves to Group B's position
   - Verify groups_data["groups"] order matches UI order
   - Verify groups.json is updated

2. **External paste:**
   - Drag Group A to Notepad → pastes "Group A\n- Task 1\n- Task 2"
   - Verify plain text format is correct
   - Verify all tasks included

3. **Drop indicator:**
   - During drag, indicator shows between groups
   - Indicator follows mouse position
   - Indicator hides on drop/leave

4. **Edge cases:**
   - Drag in flat mode (groups disabled): no drag starts
   - Drop on same position: no change
   - Drag with only one group: no visible reorder
   - Group with no tasks: still draggable, pastes just group name

5. **Conflict check:**
   - Task drag still works (distinct MIME type)
   - Group drag doesn't trigger task drop handlers
   - Task drop doesn't trigger group drop handlers

**ACCEPTANCE CRITERIA:**
- All scenarios pass
- No regressions in task drag behavior
- Groups persist correctly after reorder
- External paste format is correct

**EXPECTED OUTPUT:**
- Scenario-by-scenario verification
- Edge cases documented
- Regression check results
