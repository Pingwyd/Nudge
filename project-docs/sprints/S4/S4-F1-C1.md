# S4-F1-C1 — Add Checkbox + Clear All to HistoryDialog

**PROMPT ID:** S4-F1-C1
**MODEL:** DeepSeek V4 Flash
**TYPE:** Pure-Logic
**DEPENDS ON:** none
**TOUCHES EXISTING CODE:** Yes — HistoryDialog in main_window.py

---

**OBJECTIVE:** Add a "Don't ask for confirmation to delete" checkbox and a "Clear All" button to the History dialog.

**ROOT CAUSE:**
- `HistoryDialog` has no way to skip delete confirmations.
- `delete_history_item()` at line 695 always shows `ThemedMessageDialog.question()`.
- There is no "Clear All" button in the History window.

**REQUIREMENTS:**

1. Add a `QCheckBox` ("Don't ask for confirmation to delete") below the hint label in `HistoryDialog.init_ui()`.
2. Persist the setting in `appstate.json` via `StateManager` with key `historySkipDeleteConfirm` (default: `False`).
3. Load the setting on dialog init, save on checkbox toggle.
4. In `delete_history_item()`, check the setting before showing the confirmation dialog:
   ```python
   skip_confirm = self._state_manager.state.get("historySkipDeleteConfirm", False)
   if not skip_confirm:
       if not ThemedMessageDialog.question(...):
           return
   ```
5. Add a "Clear All" button at the bottom of the History layout (below the scroll area).
6. `clear_all_history()` method:
   - If checkbox is checked: clear immediately
   - If checkbox is unchecked: show `ThemedMessageDialog.question()` first
   - Remove all entries from `history.json` via `self.history_store.save([])`
   - Clear all row widgets from the UI
   - Update title count

**FILES TO MODIFY:**
- `src/frontend/main_window.py` — `HistoryDialog.init_ui()`, `delete_history_item()`, new `clear_all_history()`

**ACCEPTANCE CRITERIA:**
- Checkbox appears below hint label, persists across dialog reopens
- Individual delete respects checkbox setting
- Clear All button visible at bottom
- Clear All respects checkbox setting
- All history entries removed on Clear All
- Title count updates after Clear All

**BACKWARD COMPATIBILITY:**
- `historySkipDeleteConfirm` defaults to `False` — existing users get confirmations as before
- No schema changes to history.json
