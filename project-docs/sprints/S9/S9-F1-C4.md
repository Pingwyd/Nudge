# S9-F1-C4: Cache Rendered Icons

**Sprint:** 9 — Liquid Glass Aesthetic
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Cache rendered SVG icons to prevent regeneration on every theme apply.

**FILE:** `src/frontend/theme.py`

**IMPLEMENTATION:**

1. **Add icon cache dictionary:**
   ```python
   _icon_cache = {}
   ```

2. **Update generate_svg_icon to use cache:**
   ```python
   def generate_svg_icon(icon_type, color, size=24):
       cache_key = f"{icon_type}_{color}_{size}"
       if cache_key in _icon_cache:
           return _icon_cache[cache_key]
       
       # Generate SVG (existing logic)
       svg = svgs.get(icon_type, "")
       _icon_cache[cache_key] = svg
       return svg
   ```

3. **Clear cache on theme change:**
   ```python
   def clear_icon_cache():
       global _icon_cache
       _icon_cache = {}
   ```

**ACCEPTANCE CRITERIA:**
- Icons are cached after first render
- Cache is cleared on theme change
- No duplicate SVG generation
- Memory usage stays reasonable
