# S9-F1-C1: Add Glow/Shadow Effects

**Sprint:** 9 — Liquid Glass Aesthetic
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Add subtle glow effects on focused inputs and premium drop shadows on dialogs/cards.

**FILE:** `src/frontend/theme.py`

**IMPLEMENTATION:**

1. **Add glow effects for focused inputs:**
   ```python
   "input_focus_glow": f"0 0 8px {accent}33" if theme_id != "light" else f"0 0 6px {accent}22",
   ```

2. **Add drop shadow for dialogs:**
   ```python
   "dialog_shadow": "0 8px 32px rgba(0, 0, 0, 0.4)" if theme_id != "light" else "0 4px 16px rgba(0, 0, 0, 0.15)",
   ```

3. **Update input stylesheets to use glow on focus:**
   ```python
   "QLineEdit:focus { box-shadow: " + input_focus_glow + "; }"
   ```

4. **Update dialog styling to use drop shadow:**
   ```python
   "QDialog { box-shadow: " + dialog_shadow + "; }"
   ```

**ACCEPTANCE CRITERIA:**
- Focused QLineEdit shows subtle glow
- Dialogs have drop shadow
- Effects visible in Dark and OLED themes
- Effects subtle in Light theme
