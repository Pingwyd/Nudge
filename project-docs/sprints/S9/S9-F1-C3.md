# S9-F1-C3: Apply Icons to Toolbar Buttons

**Sprint:** 9 — Liquid Glass Aesthetic
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Replace text emoji/icons on toolbar buttons with themed SVG icons.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Replace emoji icons with SVG icons:**
   ```python
   from src.frontend.theme import generate_svg_icon, get_icon_color
   
   theme_id = normalize_theme_id(self.app_state.get("theme", "dark"))
   icon_color = get_icon_color(theme_id)
   
   # Settings button
   settings_icon = generate_svg_icon("settings", icon_color, 16)
   self._settings_btn.setIcon(QIcon())
   self._settings_btn.setText("")  # Remove text
   # Or use QLabel with SVG as icon
   
   # History button  
   history_icon = generate_svg_icon("history", icon_color, 16)
   
   # Search button
   search_icon = generate_svg_icon("search", icon_color, 16)
   ```

2. **Update icons on theme change:**
   ```python
   def apply_app_theme(self):
       # ... existing theme logic ...
       icon_color = get_icon_color(theme_id)
       # Re-generate and apply icons
   ```

**ACCEPTANCE CRITERIA:**
- Toolbar buttons use SVG icons instead of emoji
- Icons update when theme changes
- Icons are visible in all themes
