# S6-F1-C2: Add Hover Tooltips to HistoryRowWidget

**Sprint:** 6 — Double-Click Ambiguity
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Add tooltip to HistoryRowWidget that shows "Double-click to restore" on hover.

**FILE:** `src/frontend/main_window.py` (HistoryRowWidget or HistoryDialog row)

**IMPLEMENTATION:**

1. **In `HistoryRowWidget.__init__` or where history rows are created:**
   ```python
   self.setToolTip("Double-click to restore")
   ```

2. **Style tooltip to match glass theme** (same as TaskRowWidget):
   ```python
   self.setStyleSheet(self.styleSheet() + "QToolTip { background: rgba(30, 30, 30, 220); color: white; border: 1px solid rgba(255,255,255,0.1); padding: 4px 8px; border-radius: 4px; font-size: 12px; }")
   ```

**ACCEPTANCE CRITERIA:**
- Hovering over history row shows tooltip
- Tooltip text is "Double-click to restore"
- Tooltip styled to match glass theme
