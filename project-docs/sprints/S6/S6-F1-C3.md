# S6-F1-C3: Add Double-Click Flash Animation

**Sprint:** 6 — Double-Click Ambiguity
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Add subtle visual feedback (flash/highlight) when a task row is double-clicked.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Add flash method to TaskRowWidget:**
   ```python
   def _flash_row(self):
       """Brief highlight animation on double-click."""
       original_style = self.styleSheet()
       self.setStyleSheet(original_style + "background: rgba(255, 255, 255, 0.1);")
       QTimer.singleShot(200, lambda: self.setStyleSheet(original_style))
   ```

2. **Connect to double-click in TaskRowWidget:**
   ```python
   def mouseDoubleClickEvent(self, event):
       if self.on_toggled:
           self.on_toggled(not self._checkbox.isChecked())
           self._flash_row()
       event.accept()
   ```

3. **Add flash method to HistoryRowWidget:**
   ```python
   def _flash_row(self):
       """Brief highlight animation on double-click."""
       original_style = self.styleSheet()
       self.setStyleSheet(original_style + "background: rgba(255, 255, 255, 0.1);")
       QTimer.singleShot(200, lambda: self.setStyleSheet(original_style))
   ```

**ACCEPTANCE CRITERIA:**
- Double-clicking a task row produces brief flash (200ms)
- Double-clicking a history row produces brief flash (200ms)
- Flash uses subtle white overlay (0.1 opacity)
- No visual artifacts after flash completes
