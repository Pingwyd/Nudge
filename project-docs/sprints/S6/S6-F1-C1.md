# S6-F1-C1: Add Hover Tooltips to TaskRowWidget

**Sprint:** 6 — Double-Click Ambiguity
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Add tooltip to TaskRowWidget that shows "Double-click to complete" on hover.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **In `TaskRowWidget.__init__`:**
   ```python
   self.setToolTip("Double-click to complete")
   ```

2. **Style tooltip to match glass theme:**
   ```python
   self.setStyleSheet(self.styleSheet() + "QToolTip { background: rgba(30, 30, 30, 220); color: white; border: 1px solid rgba(255,255,255,0.1); padding: 4px 8px; border-radius: 4px; font-size: 12px; }")
   ```

**ACCEPTANCE CRITERIA:**
- Hovering over task row shows tooltip
- Tooltip text is "Double-click to complete"
- Tooltip styled to match glass theme
