# S5-F1-C4: Persist Drawer State

**Sprint:** 5 — Reminders Drawer
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Persist the drawer's open/closed state across sessions in appstate.json.

**FILES:** `src/frontend/main_window.py`, `src/backend/state_manager.py`

**IMPLEMENTATION:**

1. **In `MainWindow.__init__`** (after drawer is created):
   ```python
   # Restore drawer state
   if self.app_state.get("drawerOpen", False):
       self._drawer.open_drawer()
   ```

2. **In `MainWindow._toggle_drawer`** (or after open/close):
   ```python
   def _toggle_drawer(self):
       self._drawer.toggle_drawer()
       self.app_state["drawerOpen"] = self._drawer._is_open
       self.state_manager.save(self.app_state)
   ```

3. **Also update in `DrawerWidget.open_drawer` and `close_drawer`:**
   ```python
   def open_drawer(self):
       # ... existing logic ...
       if self._main_window:
           self._main_window.app_state["drawerOpen"] = True
           self._main_window.state_manager.save(self._main_window.app_state)
   
   def close_drawer(self):
       # ... existing logic ...
       if self._main_window:
           self._main_window.app_state["drawerOpen"] = False
           self._main_window.state_manager.save(self._main_window.app_state)
   ```

**ACCEPTANCE CRITERIA:**
- Drawer state persists in appstate.json under key "drawerOpen"
- Opening drawer on launch restores previous state
- Closing drawer persists closed state
- State saves immediately (not on app exit only)
