# S5-F1-C2: Add Chrome Bar Button

**Sprint:** 5 — Reminders Drawer
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Add a button to the main window chrome bar (toolbar) that toggles the drawer open/closed.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **In `MainWindow.__init__` or chrome bar setup area:**
   ```python
   self._drawer_btn = QPushButton("🔔")
   self._drawer_btn.setObjectName("chromeButton")
   self._drawer_btn.setToolTip("Reminders")
   self._drawer_btn.clicked.connect(self._toggle_drawer)
   ```

2. **Add button to chrome bar layout** (after existing chrome buttons, before stretch):
   ```python
   chrome_layout.addWidget(self._drawer_btn)
   ```

3. **Create drawer instance** (after chrome bar setup):
   ```python
   self._drawer = DrawerWidget(self)
   ```

4. **Add toggle method:**
   ```python
   def _toggle_drawer(self):
       self._drawer.toggle_drawer()
   ```

5. **Update drawer height on resize** (in `resizeEvent`):
   ```python
   if hasattr(self, '_drawer'):
       self._drawer.setFixedHeight(self.height())
   ```

**ACCEPTANCE CRITERIA:**
- 🔔 button appears in chrome bar
- Clicking button toggles drawer open/closed
- Drawer height matches main window height
- Button styled consistently with other chrome buttons
