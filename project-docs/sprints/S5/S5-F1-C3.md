# S5-F1-C3: Populate Drawer with Reminders

**Sprint:** 5 — Reminders Drawer
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Populate the drawer with pending reminders from TimerManager, showing task name, countdown, and cancel button.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Add method to DrawerWidget to refresh reminder list:**
   ```python
   def refresh_reminders(self):
       """Repopulate the drawer with current reminders from TimerManager."""
       # Clear existing items
       while self._list_layout.count():
           item = self._list_layout.takeAt(0)
           if item.widget():
               item.widget().deleteLater()
       
       # Get task reminders from TimerManager
       if self._main_window is None:
           return
       timer_mgr = self._main_window._timer_manager
       reminders = [t for t in timer_mgr.to_list() if t.get("taskId")]
       
       if not reminders:
           empty = QLabel("No pending reminders")
           empty.setAlignment(Qt.AlignmentFlag.AlignCenter)
           empty.setStyleSheet("color: gray; padding: 20px;")
           self._list_layout.addWidget(empty)
           return
       
       for reminder in reminders:
           row = self._create_reminder_row(reminder)
           self._list_layout.addWidget(row)
   ```

2. **Add method to create individual reminder row:**
   ```python
   def _create_reminder_row(self, reminder):
       row = QWidget()
       layout = QHBoxLayout(row)
       layout.setContentsMargins(0, 4, 0, 4)
       
       # Task name
       name = QLabel(reminder.get("name", "Unnamed"))
       name.setStyleSheet("font-size: 13px;")
       layout.addWidget(name, 1)
       
       # Countdown label
       countdown = QLabel()
       countdown.setStyleSheet("font-size: 11px; color: gray;")
       layout.addWidget(countdown)
       
       # Cancel button
       cancel_btn = QPushButton("✕")
       cancel_btn.setFixedSize(20, 20)
       cancel_btn.setObjectName("ghostButton")
       cancel_btn.clicked.connect(lambda _, tid=reminder["taskId"]: self._cancel_reminder(tid))
       layout.addWidget(cancel_btn)
       
       return row
   ```

3. **Add cancel method:**
   ```python
   def _cancel_reminder(self, task_id):
       if self._main_window:
           self._main_window._timer_manager.cancel_task_reminder(task_id)
           self.refresh_reminders()
   ```

4. **Call refresh when drawer opens:**
   ```python
   def open_drawer(self):
       if self._is_open:
           return
       self._is_open = True
       self.refresh_reminders()
       self.show()
       self._animation.setStartValue(0)
       self._animation.setEndValue(300)
       self._animation.start()
   ```

**ACCEPTANCE CRITERIA:**
- Drawer shows all pending task reminders from TimerManager
- Each row displays task name and countdown
- Cancel button removes reminder from TimerManager
- Empty state shows "No pending reminders"
- Drawer refreshes each time it opens
