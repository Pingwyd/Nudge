# S12-F1-C2: Apply Effect to Main Tasks Panel

**Sprint:** 12 — Hover Glow Animation
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Wire up the GlassShineEffect to the main tasks panel.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Initialize effect in MainWindow.__init__:**
   ```python
   # After tasks_widget is created
   self._shine_effect = GlassShineEffect(self.tasks_widget)
   self.tasks_widget.setGraphicsEffect(self._shine_effect)
   self.tasks_widget.setMouseTracking(True)
   ```

2. **Add mouse tracking to MainWindow:**
   ```python
   self.setMouseTracking(True)
   ```

3. **Override mouseMoveEvent in MainWindow:**
   ```python
   def mouseMoveEvent(self, event):
       if hasattr(self, '_shine_effect'):
           local_pos = self.tasks_widget.mapFromGlobal(event.globalPos())
           if self.tasks_widget.rect().contains(local_pos):
               self._shine_effect.set_center(local_pos)
           else:
               self._shine_effect.set_center(QPointF(-100, -100))  # Hide effect
       super().mouseMoveEvent(event)
   ```

**ACCEPTANCE CRITERIA:**
- Glow effect visible when hovering over tasks panel
- Glow hides when cursor leaves tasks panel
- No interference with task interactions (click, drag)
