# S12-F1-C1: Create GlassShineEffect

**Sprint:** 12 — Hover Glow Animation
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Create a QGraphicsEffect that renders a subtle glow following the mouse cursor.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create GlassShineEffect class:**
   ```python
   class GlassShineEffect(QGraphicsEffect):
       def __init__(self, parent=None):
           super().__init__(parent)
           self._center = QPointF(0, 0)
           self._radius = 100
           self._opacity = 0.15
       
       def set_center(self, point):
           self._center = point
           self.update()
       
       def draw(self, painter):
           # Draw subtle radial gradient at cursor position
           gradient = QRadialGradient(self._center, self._radius)
           gradient.setColorAt(0, QColor(255, 255, 255, int(255 * self._opacity)))
           gradient.setColorAt(1, QColor(255, 255, 255, 0))
           
           painter.setPen(Qt.PenStyle.NoPen)
           painter.setBrush(QBrush(gradient))
           painter.drawEllipse(self._center, self._radius, self._radius)
       
       def sourceIsPixmap(self):
           return False
   ```

2. **Apply effect to tasks widget:**
   ```python
   self._shine_effect = GlassShineEffect(self.tasks_widget)
   self.tasks_widget.setGraphicsEffect(self._shine_effect)
   ```

3. **Track mouse movement:**
   ```python
   def mouseMoveEvent(self, event):
       if hasattr(self, '_shine_effect'):
           local_pos = self.tasks_widget.mapFromGlobal(event.globalPos())
           self._shine_effect.set_center(local_pos)
       super().mouseMoveEvent(event)
   ```

**ACCEPTANCE CRITERIA:**
- GlassShineEffect class exists
- Effect renders subtle radial gradient at cursor position
- Effect follows mouse movement smoothly
