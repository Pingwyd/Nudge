# S12-F1-C3: Make Effect Optional

**Sprint:** 12 — Hover Glow Animation
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Make hover glow effect optional for performance-sensitive users.

**FILE:** `src/frontend/main_window.py`, `src/backend/state_manager.py`

**IMPLEMENTATION:**

1. **Add setting to appstate:**
   ```python
   self.app_state.setdefault("enableHoverGlow", True)
   ```

2. **Conditionally apply effect:**
   ```python
   if self.app_state.get("enableHoverGlow", True):
       self._shine_effect = GlassShineEffect(self.tasks_widget)
       self.tasks_widget.setGraphicsEffect(self._shine_effect)
   else:
       self._shine_effect = None
   ```

3. **Add toggle in Settings → Appearance tab:**
   ```python
   hover_glow_toggle = ToggleSwitchWidget()
   hover_glow_toggle.setChecked(self.app_state.get("enableHoverGlow", True))
   hover_glow_toggle.stateChanged.connect(lambda s: self._toggle_hover_glow(s == Qt.CheckState.Checked.value))
   ```

4. **Add toggle method:**
   ```python
   def _toggle_hover_glow(self, enabled):
       self.app_state["enableHoverGlow"] = enabled
       if enabled:
           self._shine_effect = GlassShineEffect(self.tasks_widget)
           self.tasks_widget.setGraphicsEffect(self._shine_effect)
       else:
           self.tasks_widget.setGraphicsEffect(None)
           self._shine_effect = None
   ```

**ACCEPTANCE CRITERIA:**
- Hover glow can be disabled in Settings
- Effect is disabled by default on first launch
- Disabling removes the effect completely
- Re-enabling restores the effect
