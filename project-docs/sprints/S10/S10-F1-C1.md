# S10-F1-C1: Create SettingsCardWidget

**Sprint:** 10 — Information Density
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Create a reusable card widget for grouping settings.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create SettingsCardWidget:**
   ```python
   class SettingsCardWidget(QFrame):
       def __init__(self, title, parent=None):
           super().__init__(parent)
           self.setObjectName("settingsCard")
           self.setStyleSheet("""
               #settingsCard {
                   border: 1px solid rgba(255, 255, 255, 0.1);
                   border-radius: 8px;
                   background: rgba(255, 255, 255, 0.03);
                   padding: 12px;
               }
           """)
           
           layout = QVBoxLayout(self)
           layout.setContentsMargins(12, 12, 12, 12)
           layout.setSpacing(8)
           
           # Card header
           header = QLabel(title)
           header.setStyleSheet("font-weight: bold; font-size: 13px; border: none;")
           layout.addWidget(header)
           
           # Content area
           self._content = QWidget()
           self._content_layout = QVBoxLayout(self._content)
           self._content_layout.setContentsMargins(0, 0, 0, 0)
           layout.addWidget(self._content)
       
       def add_widget(self, widget):
           self._content_layout.addWidget(widget)
   ```

**ACCEPTANCE CRITERIA:**
- SettingsCardWidget exists with title and content area
- Card has subtle border and background
- Content area accepts child widgets
