# S10-F1-C2: Group General Tab Settings

**Sprint:** 10 — Information Density
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Group General tab settings into visual cards (Startup & System, Window Behavior).

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create Startup & System card:**
   ```python
   startup_card = SettingsCardWidget("Startup & System")
   
   auto_start = ToggleSwitchWidget()
   auto_start.setChecked(self.app_state.get("autoStart", False))
   auto_start_row = self._create_setting_row("Run on Startup", auto_start)
   startup_card.add_widget(auto_start_row)
   
   check_updates = ToggleSwitchWidget()
   check_updates.setChecked(self.app_state.get("checkUpdates", True))
   check_updates_row = self._create_setting_row("Check for Updates", check_updates)
   startup_card.add_widget(check_updates_row)
   ```

2. **Create Window Behavior card:**
   ```python
   behavior_card = SettingsCardWidget("Window Behavior")
   
   lock_pos = ToggleSwitchWidget()
   lock_pos.setChecked(self.app_state.get("lockPosition", False))
   lock_pos_row = self._create_setting_row("Lock Position", lock_pos)
   behavior_card.add_widget(lock_pos_row)
   
   pin = ToggleSwitchWidget()
   pin.setChecked(self.app_state.get("alwaysOnTop", False))
   pin_row = self._create_setting_row("Always on Top", pin)
   behavior_card.add_widget(pin_row)
   ```

3. **Add helper to create setting row:**
   ```python
   def _create_setting_row(self, label, widget):
       row = QWidget()
       layout = QHBoxLayout(row)
       layout.setContentsMargins(0, 0, 0, 0)
       lbl = QLabel(label)
       lbl.setStyleSheet("border: none;")
       layout.addWidget(lbl)
       layout.addStretch()
       layout.addWidget(widget)
       return row
   ```

**ACCEPTANCE CRITERIA:**
- General tab shows two cards: Startup & System, Window Behavior
- Each card contains relevant toggle switches
- Settings values persist correctly
- Cards match glass theme styling
