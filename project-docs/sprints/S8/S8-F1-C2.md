# S8-F1-C2: Create Collapsible Header Widgets

**Sprint:** 8 — History Chronological Headers
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Create collapsible header widgets that expand/collapse task groups.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Create CollapsibleHeader class:**
   ```python
   class CollapsibleHeader(QWidget):
       def __init__(self, title, count, parent=None):
           super().__init__(parent)
           self._expanded = True
           self._children = []
           
           layout = QHBoxLayout(self)
           layout.setContentsMargins(0, 8, 0, 4)
           
           self._toggle_btn = QPushButton(f"▼ {title} ({count})")
           self._toggle_btn.setObjectName("ghostButton")
           self._toggle_btn.setStyleSheet("text-align: left; font-weight: bold; font-size: 13px;")
           self._toggle_btn.clicked.connect(self._toggle)
           layout.addWidget(self._toggle_btn)
       
       def _toggle(self):
           self._expanded = not self._expanded
           icon = "▼" if self._expanded else "▶"
           text = self._toggle_btn.text()
           self._toggle_btn.setText(f"{icon} {text[2:]}")
           
           for child in self._children:
               child.setVisible(self._expanded)
       
       def add_child(self, widget):
           self._children.append(widget)
   ```

2. **Wire up children in render_history:**
   ```python
   for period_name, period_entries in groups.items():
       if not period_entries:
           continue
       
       header = CollapsibleHeader(period_name, len(period_entries))
       self._scroll_layout.addWidget(header)
       
       for entry in period_entries:
           row = HistoryRowWidget(entry)
           self._scroll_layout.addWidget(row)
           header.add_child(row)
   ```

**ACCEPTANCE CRITERIA:**
- Header shows period name and entry count
- Clicking header toggles children visibility
- Arrow icon changes (▼ expanded, ▶ collapsed)
- Default state is expanded
