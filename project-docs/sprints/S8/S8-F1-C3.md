# S8-F1-C3: Replace Bracketed Text with Colorful Group Badges

**Sprint:** 8 — History Chronological Headers
**Type:** Mechanical
**Model:** DeepSeek

---

**OBJECTIVE:** Replace bracketed text `[Group]` with colorful group badges showing group name and color.

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **In HistoryRowWidget, replace text badge:**
   ```python
   # Old: [Group Name]
   # New: colored badge
   
   group_name = entry.get("groupId", "General")
   group_color = self._get_group_color(group_name)
   
   badge = QLabel(group_name)
   badge.setStyleSheet(f"""
       background: {group_color};
       color: white;
       padding: 2px 8px;
       border-radius: 10px;
       font-size: 11px;
       font-weight: bold;
   """)
   ```

2. **Add helper to get group color:**
   ```python
   def _get_group_color(self, group_id):
       """Get color for group from groups.json."""
       try:
           with open("groups.json", "r") as f:
               groups = json.load(f)
           for group in groups.get("groups", []):
               if group["id"] == group_id:
                   return group.get("color", "#4fc3f7")
       except (FileNotFoundError, json.JSONDecodeError):
           pass
       return "#4fc3f7"  # default accent color
   ```

**ACCEPTANCE CRITERIA:**
- Group name shown as colored badge (not bracketed text)
- Badge uses group color from groups.json
- Fallback to accent color if group not found
- Badge text is white for contrast
