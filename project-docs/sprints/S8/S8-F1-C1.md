# S8-F1-C1: Create Chronological Grouping Logic

**Sprint:** 8 — History Chronological Headers
**Type:** Structural
**Model:** MiMo

---

**OBJECTIVE:** Create logic to group history entries by time period (Today, Yesterday, This Week, Older).

**FILE:** `src/frontend/main_window.py`

**IMPLEMENTATION:**

1. **Add grouping method to HistoryDialog:**
   ```python
   def _group_by_time_period(self, entries):
       """Group history entries by chronological period."""
       from datetime import datetime, timedelta
       
       now = datetime.now()
       today = now.date()
       yesterday = today - timedelta(days=1)
       week_ago = today - timedelta(days=7)
       
       groups = {
           "Today": [],
           "Yesterday": [],
           "This Week": [],
           "Older": []
       }
       
       for entry in entries:
           try:
               completed_at = datetime.fromisoformat(entry.get("completedAt", ""))
               entry_date = completed_at.date()
           except (ValueError, TypeError):
               groups["Older"].append(entry)
               continue
           
           if entry_date == today:
               groups["Today"].append(entry)
           elif entry_date == yesterday:
               groups["Yesterday"].append(entry)
           elif entry_date >= week_ago:
               groups["This Week"].append(entry)
           else:
               groups["Older"].append(entry)
       
       return groups
   ```

2. **Update `render_history` to use grouping:**
   ```python
   def render_history(self):
       entries = self.history_store.load()
       filtered = self._get_filtered_entries(entries)
       groups = self._group_by_time_period(filtered)
       
       for period_name, period_entries in groups.items():
           if not period_entries:
               continue
           
           header = CollapsibleHeader(period_name, len(period_entries))
           self._scroll_layout.addWidget(header)
           
           for entry in period_entries:
               row = HistoryRowWidget(entry)
               self._scroll_layout.addWidget(row)
   ```

**ACCEPTANCE CRITERIA:**
- History entries grouped into Today, Yesterday, This Week, Older
- Empty groups are hidden (no empty headers)
- Entries with invalid/missing completedAt go to "Older"
