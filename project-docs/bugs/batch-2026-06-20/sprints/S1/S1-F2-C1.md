# S1-F2-C1 — Diagnose Tray Shortcut (Revised)

**PROMPT ID:** S1-F2-C1
**MODEL:** MiMo V2.5
**TYPE:** Architecture-Reasoning
**WHY THIS MODEL:** Requires reasoning about native event handling and Qt integration
**DEPENDS ON:** none
**CONFIDENCE IN ROOT CAUSE:** Probable
**CONTEXT:** User clarified: the issue is with the Ctrl+M shortcut key, not the minimize button.

---

## Revised Root Cause

The `GlobalHotkeyFilter` uses `ctypes.windll.user32.RegisterHotKey(None, hotkey_id, mod, vk)` with HWND=0 (thread-level registration). The `WM_HOTKEY` message is posted to the thread's message queue, but Qt's `nativeEventFilter` may not intercept it reliably on all Windows configurations.

**Why it fails:**
- `RegisterHotKey(None, ...)` posts `WM_HOTKEY` to the thread message queue
- Qt's event loop uses its own message dispatch — `nativeEventFilter` may not see all `WM_HOTKEY` messages
- The `nativeEventFilter` checks `bytes(eventType) == b"windows_dispatcher_MSG"` — this string may vary across PyQt6 versions

**Fix:** Replace `GlobalHotkeyFilter` with `QShortcut(sequence, self)` using `Qt.ShortcutContext.ApplicationShortcut`. This is:
- Cross-platform (no ctypes)
- Reliable (Qt handles the shortcut internally)
- Simpler (no native event filter needed)

**Trade-off:** `ApplicationShortcut` only fires when the app has focus. But for a tray toggle, this is acceptable — the user presses Ctrl+M while the app is visible to hide it, and when the app is hidden, they use the tray icon to restore.

---

## Architecture Decision

| Approach | Pros | Cons |
|----------|------|------|
| `GlobalHotkeyFilter` (current) | System-wide, works when app hidden | Unreliable with Qt, ctypes dependency, platform-specific |
| `QShortcut` + `ApplicationShortcut` | Reliable, cross-platform, simple | Only fires when app has focus |
| `QShortcut` + `ApplicationShortcut` + tray icon | Covers all use cases | Slightly more code |

**Decision:** Use `QShortcut` + `ApplicationShortcut` + tray icon click. This covers both keyboard toggle (when app is visible) and mouse restore (when app is hidden).
