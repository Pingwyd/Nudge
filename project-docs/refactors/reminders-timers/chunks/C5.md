# C5: Update Task Reminder Set/Clear UI to Use TimerManager

**CHANGE TYPE:** Mechanical
**BREAKING RISK:** Medium
**DEPENDS ON:** C2, C4
**ASSIGNED MODEL:** ⚡ DeepSeek V4 Flash

---

**OBJECTIVE:** All user-facing reminder operations (set, clear, custom dialog) go through TimerManager instead of writing dict fields directly.

**FILE:** `src/frontend/main_window.py`

**CHANGES:**

1. **`_set_task_reminder(task_ref, minutes_from_now, repeat=0)`** (line 3614):
   ```python
   def _set_task_reminder(self, task_ref, minutes_from_now, repeat=0):
       trigger_at = datetime.now() + timedelta(minutes=minutes_from_now)
       self._timer_manager.cancel_task_reminder(task_ref["id"])  # Clear existing
       self._timer_manager.add_task_reminder(
           task_id=task_ref["id"],
           name=task_ref.get("text", "Task reminder"),
           trigger_at=trigger_at,
           repeat_minutes=repeat,
       )
       self.app_state["timers"] = self._timer_manager.to_list()
       self.state_manager.save()
       row = self.task_row_widgets.get(id(task_ref))
       if row is not None:
           row.set_task_ref(task_ref)
   ```

2. **`_set_task_reminder_at_time(task_ref, time_str, days_ahead)`** (line 3627):
   Same pattern — compute `trigger_at`, call `cancel_task_reminder` + `add_task_reminder`.

3. **`_clear_task_reminder(task_ref)`** (line 3643):
   ```python
   def _clear_task_reminder(self, task_ref):
       self._timer_manager.cancel_task_reminder(task_ref["id"])
       self.app_state["timers"] = self._timer_manager.to_list()
       self.state_manager.save()
       row = self.task_row_widgets.get(id(task_ref))
       if row is not None:
           row.set_task_ref(task_ref)
   ```

4. **`_show_custom_reminder_dialog(task_ref)`** (line 3652):
   The dialog itself doesn't change — it still computes a `trigger_at` datetime and returns it. The calling code (after dialog.accept()) changes from writing dict fields to calling `timer_manager.add_task_reminder()`.

5. **Context menu "Clear Reminder"** (line 2960):
   Already calls `_clear_task_reminder(task_ref)` — no change needed.

6. **Pre-populate custom dialog with existing reminder:**
   Currently reads `task_ref.get("reminderAt")` to pre-fill the date/time. Change to:
   ```python
   existing = self._timer_manager.get_timer_for_task(task_ref["id"])
   if existing:
       pre_fill_dt = datetime.fromtimestamp(existing.next_trigger_at)
   ```

- Custom dialog pre-fills from TimerManager
- No `reminderAt`/`reminderFired`/`reminderRepeat` fields are written to task dicts
