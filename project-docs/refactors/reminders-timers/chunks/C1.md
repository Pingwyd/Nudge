# C1: Extend TimerConfig with task_id Field

**CHANGE TYPE:** Mechanical
**BREAKING RISK:** Low
**DEPENDS ON:** None
**ASSIGNED MODEL:** ⚡ DeepSeek V4 Flash

---

**OBJECTIVE:** Add a `task_id` field to `TimerConfig` so that timers can optionally reference a task. Existing generic timers remain unaffected (task_id defaults to None).

**FILE:** `src/backend/timer_manager.py`

**CHANGES:**

1. Add `task_id: str | None = None` parameter to `TimerConfig.__init__`
2. Store as `self.task_id = task_id`
3. In `to_dict()`: add `"taskId": self.task_id` to output
4. In `from_dict()`: read `d.get("taskId")` with default `None`
5. In `add()` method of `TimerManager`: accept optional `task_id` parameter, pass to `TimerConfig`

**ACCEPTANCE CRITERIA:**
- Existing generic timers still load/save correctly (task_id = None)
- New timers with task_id serialize and deserialize correctly
- `from_dict` gracefully handles old dicts without "taskId" key (returns None)
- No existing tests break
- All 9 previously passing syntax checks still pass

**NO BEHAVIOR CHANGE** — this is purely additive. No code reads `task_id` yet.
