# C3: Migrate Existing Task Reminders to TimerManager

**CHANGE TYPE:** Structural
**BREAKING RISK:** Medium
**DEPENDS ON:** C1, C2
**ASSIGNED MODEL:** 🧠 MiMo V2.5

---

**OBJECTIVE:** One-time migration at boot to move any task reminder fields from tasks.json into TimerManager (appstate.json["timers"]).

**FILE:** `src/frontend/main_window.py` (init sequence)

**CHANGES:**

In `MainWindow.__init__`, BEFORE `timer_manager.load()`:

1. Add `_migrate_task_reminders()` method:
   ```python
   def _migrate_task_reminders(self):
       migrated = False
       for task in self.tasks:
           reminder_str = task.get("reminderAt")
           if not reminder_str:
               continue
           try:
               reminder_dt = datetime.fromisoformat(reminder_str)
           except (ValueError, TypeError):
               # Bad data — strip it
               for key in ("reminderAt", "reminderFired", "reminderRepeat"):
                   task.pop(key, None)
               migrated = True
               continue
           if datetime.now() >= reminder_dt and not task.get("reminderFired", False):
               # Already due — fire immediately via TimerManager
               pass  # TimerManager will handle this on next tick
           repeat = task.get("reminderRepeat", 0)
           self._timer_manager.add_task_reminder(
               task_id=task["id"],
               name=task.get("text", "Task reminder"),
               trigger_at=reminder_dt,
               repeat_minutes=repeat,
           )
           # Strip reminder fields from task
           for key in ("reminderAt", "reminderFired", "reminderRepeat"):
               task.pop(key, None)
           migrated = True
       if migrated:
           self.store.save(self.tasks)
   ```

2. Call `_migrate_task_reminders()` after creating `self._timer_manager` but before `timer_manager.load()`. Actually — the migration needs `timer_manager` to be loaded first, so the order should be:
   - Create `_timer_manager`
   - Load `_timer_manager` from appstate (existing generic timers)
   - Run `_migrate_task_reminders()` (adds task reminders to the loaded manager)
   - Save both stores

3. Guard against double-migration: check if any tasks still have `reminderAt` before running. If none, skip.

**ACCEPTANCE CRITERIA:**
- Tasks with `reminderAt` are migrated to TimerManager entries
- `reminderAt`/`reminderFired`/`reminderRepeat` fields are stripped from tasks.json
- Generic timers in appstate.json are preserved (not duplicated)
- If no tasks have reminders, migration is a no-op
- tasks.json is saved after migration
- appstate.json["timers"] includes both old generic + new task-linked entries
- All syntax checks pass

**ROLLBACK:** If migration fails, the original reminder fields remain on tasks. The old polling loop (C4) is not yet removed, so reminders still work via the old path until migration succeeds.
