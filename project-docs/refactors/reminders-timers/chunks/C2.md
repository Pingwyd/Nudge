# C2: Add Task-Reminder Methods to TimerManager

**CHANGE TYPE:** Structural
**BREAKING RISK:** Low
**DEPENDS ON:** C1
**ASSIGNED MODEL:** 🧠 MiMo V2.5

---

**OBJECTIVE:** Add convenience methods to TimerManager for task-linked timer operations: add, lookup, cancel.

**FILE:** `src/backend/timer_manager.py`

**CHANGES:**

1. Add `add_task_reminder(task_id, name, trigger_at, repeat_minutes=0) -> str`:
   - Converts `trigger_at` (datetime or ISO string) to epoch `next_trigger_at`
   - Calls `self.add(name, interval_seconds=0, repeat=False)` then patches the config:
     - Sets `cfg.task_id = task_id`
     - Sets `cfg.next_trigger_at = trigger_at_epoch`
     - If `repeat_minutes > 0`: sets `cfg.repeat = True` and stores repeat interval
   - Starts the Qt timer for this config
   - Returns `timer_id`

2. Add `get_timer_for_task(task_id) -> TimerConfig | None`:
   - Iterates `self._timers.values()`, returns first where `cfg.task_id == task_id`

3. Add `cancel_task_reminder(task_id) -> bool`:
   - Calls `get_timer_for_task(task_id)`, then `self.remove(timer_id)` if found
   - Returns whether a timer was removed

4. Add `get_repeat_minutes(cfg) -> int`:
   - Helper to extract repeat interval from a TimerConfig (needed because generic timers use `repeat=True` but don't store the interval in minutes)

**ACCEPTANCE CRITERIA:**
- `add_task_reminder` creates a TimerConfig with task_id set
- `get_timer_for_task` finds it by task_id
- `cancel_task_reminder` removes it and stops the Qt timer
- `get_timer_for_task` returns None for non-existent task_id
- Generic timers (no task_id) are unaffected
- All syntax checks pass

**NOTE:** The `interval_seconds` parameter is repurposed here — for task reminders, the "interval" is the time until first trigger (not a repeating interval). The `repeat` field and a stored `repeat_minutes` value handle actual repetition.
