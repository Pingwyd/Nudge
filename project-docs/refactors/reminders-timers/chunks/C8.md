# C8: Fix Archive/Delete to Cancel Task Reminders

**CHANGE TYPE:** Mechanical
**BREAKING RISK:** Low
**DEPENDS ON:** C2
**ASSIGNED MODEL:** ⚡ DeepSeek V4 Flash

---

**OBJECTIVE:** When a task is archived or deleted, its associated timer reminder is explicitly cancelled. When a task is restored, no stale reminder data exists.

**FILE:** `src/frontend/main_window.py`

**CHANGES:**

1. **`archive_task(task_ref)`** (line 3271):
   Add `self._timer_manager.cancel_task_reminder(task_ref["id"])` before the task is moved to history.

2. **`delete_task(task_ref)`** (line 3255):
   Add `self._timer_manager.cancel_task_reminder(task_ref["id"])` before the task is removed.

3. **`restore_task_from_history(task_ref)`** (line 3327):
   The restored task should NOT have any reminder fields (they were removed by C3/C5). Add a safety strip:
   ```python
   for key in ("reminderAt", "reminderFired", "reminderRepeat"):
       restored_task.pop(key, None)
   ```

4. **`_undo_last_archive()`** (line 3304):
   Calls `restore_task_from_history` — inherits the fix above.

5. **`clear_completed_tasks()`** (line 3379):
   Bulk archive. Each task goes through `archive_task()`, which now cancels reminders. No additional change needed.

6. **`_delete_group(group_id)`** (line 2706):
   Moves tasks to General — no reminder cancellation needed since tasks aren't deleted.

**ACCEPTANCE CRITERIA:**
- Archiving a task cancels its timer reminder (no orphaned timer)
- Deleting a task cancels its timer reminder
- Restoring a task does NOT bring back a stale reminder
- TimerManager timer count decreases after archive/delete
- appstate.json["timers"] is saved after cancellation
- All syntax checks pass
