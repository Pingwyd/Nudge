# C7: Fix Countdown Label to Read from TimerManager

**CHANGE TYPE:** Structural
**BREAKING RISK:** Medium
**DEPENDS ON:** C2, C4
**ASSIGNED MODEL:** 🧠 MiMo V2.5

---

**OBJECTIVE:** TaskRowWidget's countdown label reads reminder time from TimerManager instead of `task.get("reminderAt")`.

**FILE:** `src/frontend/main_window.py` (TaskRowWidget class)

**CHANGES:**

1. **`set_task_ref(task_ref)`** (line 339):
   Currently:
   ```python
   def set_task_ref(self, task_ref):
       self._task_ref = task_ref
       if task_ref.get("reminderAt") and not task_ref.get("reminderFired", False):
           self._start_countdown()
       else:
           self._stop_countdown()
   ```
   
   Change to:
   ```python
   def set_task_ref(self, task_ref):
       self._task_ref = task_ref
       # Check TimerManager for active reminder
       has_reminder = False
       if self._main_window and hasattr(self._main_window, '_timer_manager'):
           cfg = self._main_window._timer_manager.get_timer_for_task(task_ref["id"])
           if cfg is not None and cfg.enabled:
               has_reminder = True
       if has_reminder:
           self._start_countdown()
       else:
           self._stop_countdown()
   ```

2. **`_start_countdown()`** (line 346):
   Currently reads `self._task_ref.get("reminderAt")`. Change to read from TimerManager:
   ```python
   def _start_countdown(self):
       if self._countdown_timer is None:
           self._countdown_timer = QTimer(self)
           self._countdown_timer.timeout.connect(self._update_countdown)
       self._countdown_label.show()
       self._apply_countdown_theme()
       self._update_countdown()
       self._countdown_timer.start(1000)
   ```

3. **`_update_countdown()`** (line 357):
   Currently:
   ```python
   def _update_countdown(self):
       reminder_str = self._task_ref.get("reminderAt")
       ...
   ```
   
   Change to:
   ```python
   def _update_countdown(self):
       trigger_at = None
       if self._main_window and hasattr(self._main_window, '_timer_manager'):
           cfg = self._main_window._timer_manager.get_timer_for_task(self._task_ref["id"])
           if cfg is not None:
               trigger_at = cfg.next_trigger_at
       if trigger_at is None:
           self._stop_countdown()
           return
       remaining = int(trigger_at - datetime.now().timestamp())
       if remaining <= 0:
           self._stop_countdown()
           return
       hours, remainder = divmod(remaining, 3600)
       minutes, secs = divmod(remainder, 60)
       if hours > 0:
           self._countdown_label.setText(f"{hours}h {minutes}m {secs}s")
       elif minutes > 0:
           self._countdown_label.setText(f"{minutes}m {secs}s")
       else:
           self._countdown_label.setText(f"{secs}s")
   ```

**ACCEPTANCE CRITERIA:**
- Countdown label shows correct remaining time
- Countdown label updates every second
- Countdown label hides when reminder fires or is cleared
- Countdown label works for repeating reminders (shows time until next trigger)
- No reference to `task.get("reminderAt")` remains in TaskRowWidget
- All syntax checks pass
