# C4: Replace Polling Loop with TimerManager Signals

**CHANGE TYPE:** Structural
**BREAKING RISK:** High
**DEPENDS ON:** C2, C3
**ASSIGNED MODEL:** 🧠 MiMo V2.5

---

**OBJECTIVE:** Eliminate the 15-second polling loop. All task reminders now fire through TimerManager's event-driven QTimer system.

**FILE:** `src/frontend/main_window.py`

**CHANGES:**

1. **Remove** `_task_reminder_timer` creation (line 1930-1933):
   ```python
   # DELETE:
   self._task_reminder_timer = QTimer(self)
   self._task_reminder_timer.timeout.connect(self._check_task_reminders)
   self._task_reminder_timer.start(TASK_REMINDER_CHECK_MS)
   ```

2. **Remove** `_check_task_reminders()` method entirely (lines 3583-3612)

3. **Extend** `_on_timer_fired()` (line 3566) to handle task-linked timers:
   ```python
   def _on_timer_fired(self, timer_id: str, name: str):
       cfg = self._timer_manager._timers.get(timer_id)
       if cfg is not None and cfg.task_id is not None:
           # Task-linked reminder
           task = next((t for t in self.tasks if t["id"] == cfg.task_id), None)
           if task is not None:
               task_text = task.get("text", name)
               self._tray.show_message("Nudge", f"Reminder: {task_text}")
               row = self.task_row_widgets.get(id(task))
               if row is not None:
                   row.set_task_ref(task)  # Updates countdown display
           else:
               # Task was deleted — cancel this orphaned timer
               self._timer_manager.cancel_task_reminder(cfg.task_id)
       else:
           # Generic timer
           self._tray.show_message("Nudge", f"Reminder: {name}")
       self.app_state["timers"] = self._timer_manager.to_list()
       self.state_manager.save()
   ```

4. **Import cleanup:** Remove `TASK_REMINDER_CHECK_MS` from imports in main_window.py (it was used only for the polling interval).

**ACCEPTANCE CRITERIA:**
- No `QTimer` polling for task reminders exists
- Task reminders fire at exact due time (not ±15s)
- Generic timers still fire correctly
- Orphaned timers (task deleted while reminder active) are auto-cleaned
- Tray notification shows correct task text
- `_check_task_reminders` method does not exist
- All syntax checks pass

**MIGRATION NOTE:** This chunk assumes C3 has already migrated all existing task reminders into TimerManager. If C3 hasn't run yet, any task with `reminderAt` fields will have those reminders silently ignored (the polling loop is gone). This is why C3 MUST come before C4.
