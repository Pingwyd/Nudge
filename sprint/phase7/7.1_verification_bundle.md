# Phase 7.1 — End-to-End Verification Bundle

## Objective
Verify every feature across all phases works correctly, both individually and together. Run through the entire checklist and fix any regressions.

## Verification Checklist

### Phase 1 — Critical Bug Fixes
- [ ] Add a new task after changing text size — text displays at correct size, no clipping
- [ ] Resize window to minimum — text column never collapses below 100px
- [ ] Long task (5+ wrapped lines) — all text visible, descenders not clipped
- [ ] Dark theme applies to main window, context menus, History, Export, Settings
- [ ] Light theme applies consistently across all UI
- [ ] Toggle Always on Top on/off — no text loss, no visual corruption
- [ ] Toggle Pin to Desktop — works without breaking task list
- [ ] Add task while AoT enabled — existing text preserved

### Phase 5 — New Features
- [ ] First launch → Welcome dialog appears
- [ ] Version change → What's New dialog shows with correct changelog
- [ ] ❤️ Donate button opens Flutterwave in browser
- [ ] Changelog dialog shows all versions with formatted HTML
- [ ] All dialogs themed correctly in both dark and light modes

### Phase 6 — App Optimization
- [ ] PyInstaller build completes without errors
- [ ] Built exe launches and starts correctly
- [ ] Startup time is acceptable (<3s)
- [ ] No unnecessary windows/consoles on launch
- [ ] Task list with 100 items renders without lag
- [ ] Resize window rapidly — no jank
- [ ] Memory usage stable after repeated add/delete cycles
- [ ] No dialog leaks after 20 open/close cycles

### Cross-Phase — Integration
- [ ] Task add → edit → delete → undo from History
- [ ] Groups: create, rename, collapse, move tasks between groups
- [ ] Drag reorder works within and between groups
- [ ] Context menu: Edit, Move Up/Down, Move to Top/Bottom, Move to Group, Delete
- [ ] System tray: hide to tray, show from tray, quit from tray
- [ ] Settings: change text size → immediately reflected in task list
- [ ] Settings: toggle theme → all UI updates immediately
- [ ] Settings: toggle groups on/off → layout adjusts
- [ ] Export: CSV and JSON export produce valid files
- [ ] Export: file saves to chosen location

### Final Sanity
- [ ] App starts cleanly (no ImportError, no traceback)
- [ ] No console errors during normal operation
- [ ] All dialogs are dismissible (Esc key or Close button)
- [ ] Window is resizable and remembers position/size
- [ ] Double-click task toggles completion
- [ ] Edit → Enter commits, Esc cancels

## Regression Fix Procedure
For each failing checkbox:
1. Identify the affected file and line
2. Read the current code
3. Apply minimal fix
4. Re-verify
5. Note the fix in a comment

## Final Report
After completing all checks, produce a summary:
- Passed: X/Y
- Failed: (list with file:line references)
- Fixed: (list of applied fixes)
