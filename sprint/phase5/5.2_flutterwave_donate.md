# Phase 5.2 — Flutterwave Donate Button

## Objective
Add a ❤️ Donate button that opens the Flutterwave payment link in the default browser.

## Implementation

### Step 1 — Add chrome button in main_window.py

Add a donate button alongside other chrome buttons:

```python
self.donate_btn = QPushButton("❤️")
self.donate_btn.setObjectName("chromeButton")
self.donate_btn.setToolTip("Support Nudge — Donate")
self.donate_btn.clicked.connect(self._open_donate_link)
```

Insert in the chrome button layout (e.g., next to Settings).

### Step 2 — Add `_open_donate_link` method

```python
def _open_donate_link(self):
    """Open Flutterwave donate page in browser."""
    import webbrowser
    webbrowser.open("https://flutterwave.com/pay/nudge")
```

### Step 3 — Add confirmation before opening (optional)

```python
def _open_donate_link(self):
    from PyQt6.QtWidgets import QMessageBox
    reply = QMessageBox.question(
        self,
        "Support Nudge",
        "You'll be taken to Flutterwave to complete your donation.\n\n"
        "Open browser?",
        QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.No,
        QMessageBox.StandardButton.Yes,
    )
    if reply == QMessageBox.StandardButton.Yes:
        import webbrowser
        webbrowser.open("https://flutterwave.com/pay/nudge")
```

## Verification
1. ❤️ button visible in title bar
2. Click → confirmation dialog appears
3. Confirm → default browser opens to Flutterwave payment page
4. Cancel → nothing happens
