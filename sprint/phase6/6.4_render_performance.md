# Phase 6.4 — Render Performance

## Objective
Optimize task rendering to reduce lag when adding/removing many tasks or resizing quickly.

## Implementation

### Step 1 — Profile current render performance

Add timing instrumentation:

```python
import time

def render_tasks(self):
    t0 = time.perf_counter()
    # ... existing code ...
    elapsed = time.perf_counter() - t0
    if elapsed > 0.05:
        print(f"[perf] render_tasks: {elapsed:.3f}s ({len(self.tasks)} tasks)")
```

### Step 2 — Batch UI updates

Wrap bulk operations in `setUpdatesEnabled(False/True)`:

```python
def render_tasks(self):
    self.tasks_widget.setUpdatesEnabled(False)
    # ... existing code ...
    self.tasks_widget.setUpdatesEnabled(True)
```

### Step 3 — Minimize layout re-validation

Replace `addStretch(1)` with a fixed spacer that doesn't trigger relayout:

```python
# Instead of self.tasks_layout.addStretch(1)
# Use a fixed spacer widget that's set once
if not hasattr(self, '_bottom_spacer'):
    self._bottom_spacer = QWidget()
    self._bottom_spacer.setSizePolicy(QSizePolicy.Policy.Expanding, QSizePolicy.Policy.Expanding)
    self.tasks_layout.addWidget(self._bottom_spacer)
```

### Step 4 — Debounce resize events

```python
def resizeEvent(self, event):
    super().resizeEvent(event)
    # Debounce: only sync text layouts 100ms after last resize
    if hasattr(self, '_resize_timer') and self._resize_timer.isActive():
        self._resize_timer.stop()
    else:
        self._resize_timer = QTimer(self)
        self._resize_timer.setSingleShot(True)
        self._resize_timer.timeout.connect(self._sync_task_row_text_layouts)
    self._resize_timer.start(100)
```

### Step 5 — Cache rendered rows

For large task lists (>100 tasks), consider virtual scrolling or limiting visible rows.
