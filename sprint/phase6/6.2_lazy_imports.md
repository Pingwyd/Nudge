# Phase 6.2 — Lazy Imports

## Objective
Move heavy imports (`PyQt6.QtWidgets`, etc.) inside functions rather than at module top-level to improve startup time.

## Implementation

### Step 1 — Profile current startup

Create a simple profiling script:

```python
"""Profile import time for each module."""
import time

start = time.time()
import src.main
print(f"Import time: {time.time() - start:.3f}s")
```

Run it to establish baseline.

### Step 2 — Apply lazy imports in main_window.py

Replace top-level Qt imports with local imports inside methods:

**Before:**
```python
from PyQt6.QtWidgets import QApplication, QDialog, QHBoxLayout, ...
from PyQt6.QtCore import Qt, QTimer, ...
```

**After:**
```python
# Keep only the most commonly used imports at top
from PyQt6.QtCore import Qt, QTimer
from PyQt6.QtWidgets import QWidget, QVBoxLayout, QHBoxLayout, QPushButton, QLabel

# Move less common imports into methods
def some_method(self):
    from PyQt6.QtWidgets import QDialog, QMessageBox, QFileDialog
    ...
```

### Step 3 — Apply lazy imports in dialog files

Apply the same pattern to `settings_dialog.py`, `history_dialog.py`, `export_dialog.py`, `update_dialog.py`, `tutorial_dialog.py`, and `changelog_dialog.py`.

### Step 4 — Apply lazy imports in state_manager.py

```python
class StateManager:
    def load(self):
        import json  # lazy — only needed for file I/O
        ...
```

## Verification
1. Measure startup time before and after (aim for ≥20% reduction)
2. All features work correctly after lazy imports
3. No circular import issues introduced
