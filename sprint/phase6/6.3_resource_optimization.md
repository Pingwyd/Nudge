# Phase 6.3 — Resource Optimization

## Objective
Reduce memory footprint and disk usage by optimizing images, fonts, and static resources.

## Implementation

### Step 1 — Audit resources

Check for:
- Embedded images/icons (PNG, SVG) — optimize size
- Font files — remove unused weights
- QSS stylesheets — consolidate duplicates

### Step 2 — Optimize icons

If using PNG icons:
```python
# Convert to simpler representation or use QPainter-based drawing
# instead of loading image files
```

Replace image-based icons with:
- Unicode/emoji characters (already used for 🕒, ⚙)
- QStyle standard pixmaps
- QPainter-drawn icons

### Step 3 — Consolidate stylesheets

Create `src/backend/styles.py`:

```python
"""Shared stylesheet fragments to avoid duplication."""

def button_style(theme):
    return f"""
        QPushButton {{
            background: {theme["accent"]};
            color: {theme["buttonFg"]};
            border: none;
            padding: 6px 14px;
            border-radius: 4px;
        }}
        QPushButton:hover {{
            opacity: 0.9;
        }}
    """

def input_style(theme):
    return f"""
        QLineEdit {{
            background: {theme["cardBg"]};
            color: {theme["fg"]};
            border: 1px solid {theme.get("border", "#444")};
            padding: 4px 8px;
            border-radius: 4px;
        }}
    """
```

### Step 4 — Remove unused QSS

Search for inline stylesheet strings that duplicate or contradict each other. Remove or consolidate.

## Verification
1. App runs with same visual appearance
2. No broken styles or missing icons
3. Reduced memory usage (check with Task Manager)
4. All buttons, inputs, and dialogs styled correctly
