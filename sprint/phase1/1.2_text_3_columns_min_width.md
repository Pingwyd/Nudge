# Phase 1.2 — Fix Three-Column Text Collapse at Minimum Width

## Problem
When the window is at minimum width, the text column collapses to 0 visible pixels, making all tasks unreadable.

## Root Cause
`available_text_width()` in `responsive_text.py:73` returns at least `MIN_TEXT_COLUMN_WIDTH` (180px), but the layout's total available width at minimum window size is less than 180px + checkbox + Edit button + margins. The minimum width set on the label causes layout conflicts, and the label either overflows or gets clipped to 0.

## Fix

### Step 1 — Make MIN_TEXT_COLUMN_WIDTH proportional (responsive_text.py:16)

```python
# Replace the hardcoded constant with a function
def min_text_column_width(available_width: int) -> int:
    """At least 40% of available width, never below 100px."""
    return max(100, int(available_width * 0.4))
```

### Step 2 — Update `apply_wrapped_text_width` and `available_text_width` (responsive_text.py:28–34, 73–98)

In `apply_wrapped_text_width`:
```python
def apply_wrapped_text_width(label: QLabel, available_width: int) -> None:
    width = max(1, available_width)
    label.setMaximumWidth(width)
    min_width = min(width, int(available_width * 0.4))
    min_width = max(min_width, min_text_column_width(available_width))
    label.setMinimumWidth(min_width)
    label.adjustSize()
```

In `available_text_width`, replace the last line:
```python
    return max(min_text_column_width(available), available)
```
