# Phase 1.3 — Fix Text Clipping When Edit Button Below Text

## Problem
When text wraps to multiple lines, the last line is clipped (partially hidden) behind the Edit button row.

## Root Cause
`TaskRowWidget._sync_content_stack_height` at `main_window.py:296` computes height for the label using `label_content_height`, but this doesn't account for the vertical offset between the label top and the Edit button baseline when the label wraps.

## Fix

### Step 1 — Update `_sync_content_stack_height` (main_window.py:296–310)

```python
def _sync_content_stack_height(self):
    """Content stack height accounts for full wrapped text height."""
    ht_reserved = [self.edit_btn]
    if self._indent_spacer is not None:
        ht_reserved.insert(0, self._indent_spacer)
    column_width = available_text_width(self, ht_reserved)
    if self._editing:
        apply_editor_field_width(self.editor, column_width)
        fix_single_line_editor_height(self.editor)
        sync_stacked_page_height(self.content_stack, self.editor.height())
    else:
        label_height = label_content_height(self.label, column_width)
        # Add 2px breathing room so descenders aren't clipped
        sync_stacked_page_height(self.content_stack, label_height + 2)
```

### Step 2 — Ensure Edit button aligns with the bottom of the text stack (main_window.py:261)

```python
# In __init__, change the Edit button alignment:
layout.addWidget(self.edit_btn, 0, Qt.AlignmentFlag.AlignBottom)
```
