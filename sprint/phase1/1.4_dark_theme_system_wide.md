# Phase 1.4 — Dark Theme Applies System-Wide (Not Just Settings)

## Problem
Dark theme only applies within the Settings dialog. Main window, context menus, History dialog, and Export dialog remain in light/system theme.

## Root Cause
Theme application is triggered only when `settings_dialog.py` saves. The main window's `apply_app_theme()` is called only from settings' save handler, and context menus are styled inline per-dialog.

## Fix

### Step 1 — Ensure `apply_app_theme` saves AND reapplies (main_window.py)

Find the `apply_app_theme` method. It should:

```python
def apply_app_theme(self, theme_id=None):
    """Apply theme to the entire application."""
    if theme_id is None:
        theme_id = normalize_theme_id(self.app_state.get("theme", "dark"))
    else:
        self.app_state["theme"] = theme_id
    theme = get_theme(theme_id)
    
    # Save to persistent state
    self.state_manager.state["theme"] = theme_id
    self.state_manager.save()
    
    # Apply to main window
    self.setStyleSheet(app_stylesheet(theme))
    
    # Re-style any open dialogs
    for dialog in self.findChildren(QDialog):
        dialog.setStyleSheet(dialog_stylesheet(theme))
    
    # Re-style context menus by updating palette
    palette = self._build_palette(theme)
    QApplication.setPalette(palette)
```

### Step 2 — Create `_build_palette` helper (main_window.py)

```python
def _build_palette(self, theme):
    """Build a QPalette from theme tokens for system-level styling."""
    from PyQt6.QtGui import QPalette, QColor
    palette = QPalette()
    bg = QColor(theme.get("windowBg", "#1a1a2e"))
    fg = QColor(theme.get("fg", "#e0e0e0"))
    palette.setColor(QPalette.ColorRole.Window, bg)
    palette.setColor(QPalette.ColorRole.WindowText, fg)
    palette.setColor(QPalette.ColorRole.Base, QColor(theme.get("cardBg", "#16213e")))
    palette.setColor(QPalette.ColorRole.Text, fg)
    palette.setColor(QPalette.ColorRole.Button, bg)
    palette.setColor(QPalette.ColorRole.ButtonText, fg)
    palette.setColor(QPalette.ColorRole.Highlight, QColor(theme.get("accent", "#4fc3f7")))
    palette.setColor(QPalette.ColorRole.HighlightedText, QColor("#ffffff"))
    palette.setColor(QPalette.ColorRole.ToolTipBase, QColor(theme.get("cardBg", "#16213e")))
    palette.setColor(QPalette.ColorRole.ToolTipText, fg)
    return palette
```
