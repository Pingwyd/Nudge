# Phase 1.5 — Always-on-Topy: Adding a Task Loses Existing Text

## Problem
When "Always on Top" (AoT) is enabled, adding a new task causes all existing task text to disappear or show as blank.

## Root Cause
`window_layer.py:11` composes window flags. When `WindowStaysOnTopHint` is set, the widget re-creation or flag change triggers a relayout that resets text rendering. The flag change in `main_window.py` (likely around the settings save handler) causes the entire task list widget to repaint before text sizes are re-applied.

## Fix

### Step 1 — Ensure window flags are reapplied without triggering full rebuild (main_window.py)

Find where `always_on_top` toggle is handled (search for `setWindowFlags` or `WindowStaysOnTopHint`). Change the approach to:

```python
def _apply_window_layer(self):
    """Apply window layer (AoT / Pin to Desktop) without rebuilding task list."""
    from src.backend.window_layer import compose_main_window_flags, reconcile_layer_settings
    
    reconcile_layer_settings(self.app_state)
    flags = compose_main_window_flags(
        self.app_state.get("pinnedToDesktop", False),
        self.app_state.get("alwaysOnTop", False),
    )
    
    # Store current geometry
    geo = self.geometry()
    
    # Update flags
    self.setWindowFlags(flags)
    
    # Restore geometry (setWindowFlags resets it)
    self.setGeometry(geo)
    
    # Force full repaint
    self.show()
    
    # Re-sync text layouts after flag change
    QTimer.singleShot(0, self._sync_task_row_text_layouts)
```

### Step 2 — Ensure `_sync_task_row_text_layouts` exists (main_window.py)

Search for this method. If it doesn't exist, add:

```python
def _sync_task_row_text_layouts(self):
    """Re-sync text wrapping for all visible task rows."""
    for row in self.task_row_widgets.values():
        if row is not None:
            row.sync_text_layout()
```

4. Add several tasks — all should render correctly
5. Disable AoT → no text loss
